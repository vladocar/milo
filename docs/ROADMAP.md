# Roadmap

## Available

Standalone Milo 0.3 provides readable blocks, dynamic values, collections, functions, a C++ bytecode compiler/VM, REPL, syntax checks, and bytecode inspection. The separate Playground adds browser learning and creative tools.

## Proposed work

These are ideas, not implemented features or promised releases:

1. Expand language documentation and command-line examples.
2. Add repeatable Windows/macOS build coverage.
3. Consolidate native and browser sources around a shared core.
4. Define versioning and compatibility rules.
5. Improve debugging and editor support.
6. Explore modules and a small standard library.

Keep syntax decisions tied to beginner needs and performance work tied to measurement. Package installation, classes, JIT, and machine-code compilation are not present.
