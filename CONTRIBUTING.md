# Contributing to Milo

The main project is the language. The Playground is its companion demo.

Report bugs with a short `.milo` program, expected/actual output, runtime version, OS, and CLI/browser context. Remove private information from answers and screenshots.

For syntax ideas, explain the learner benefit with an example. Distinguish proposals from working features.

For a pull request:

1. Create a focused branch.
2. Follow [development](docs/DEVELOPMENT.md).
3. Add meaningful regression coverage for behavior changes.
4. Check examples and error messages.
5. Update documentation and explain verification and unrun checks.

Standalone and browser sources are separate snapshots. Port common changes deliberately rather than overwriting one copy with the other. For browser work, check keyboard access, narrow screens, and saved-project compatibility.

Keep [MIT](LICENSE) and font notices. Submit work you have the right to contribute under the project's license.
